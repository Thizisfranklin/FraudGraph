# FraudGraph: Neon Ledger City

**An original, story-first React experience grounded in the actual FraudGraph research evidence.**

This is a separate application from the existing [FraudGraph Investigator](../app/README.md). The story uses Vite, React, TypeScript, Tailwind, Framer Motion, React Flow, and *only original SVG/CSS artwork*. It does not copy any game logo, character, map, asset, soundtrack, or layout.

## Run locally

```bash
cd story
npm install
npm run dev
```

The app needs `src/data/data.ts`. This is the **only file holding research numbers** and is generated from tracked source reports + the actual historical GitHub Actions experiment artifacts, with no fabricated metrics.

To regenerate it from downloaded experiment folders:

```bash
python scripts/generate_story_data.py \
  --temporal .research/temporal \
  --robustness .research/robustness
```

The [Neon Ledger City workflow](../.github/workflows/neon-ledger-city.yml) obtains source artifacts from pinned completed runs, regenerates the module, validates it, builds a single-file offline HTML, and packages the previous React Investigator at `/investigator`. The generated `data.ts` is committed to the source branch for durable future builds.

## Experience

- Scroll-linked chapter descent with accessible skip navigation and progress.
- Five CSS-variable themes with a retro radio dial.
- Read mode and Play mode with identical measurements and caveats.
- Original skyline, palm and sunset SVG/CSS graphics and a low-motion alternative.
- A real directed Bitcoin network explorer with source-backed transaction IDs.
- Interactive comparison of original XGBoost/Logistic AP, per-bucket failure, review capacity, feature drift, strategy evaluation, robustness folds, and saved capacity observations.
- Every unavailable strategy+period+review-budget outcome displays `-- awaiting data --`, never a made-up result.
- Evidence vault with source links and notebook status.
- Optional synthesized UI tones off by default; no copyrighted music.
- A hidden chaos theme is visual only and does not modify data.

## Strict research contract

Original model results, later validation experiments, and post-hoc replay remain separately labeled. Known illicit / known licit labels are **dataset labels** and never a claim of individual guilt. Unknown outcomes remain unknown, even in analyst queues. A score is *not* a calibrated probability. Graph snapshots assume **end-of-time-bucket batch processing**, not real-time fraud detection. The cause of the observed temporal failure is unresolved, and prospective effectiveness was never measured.

## Publishing

The GitHub Actions job builds `story/dist/index.html` as an **offline-capable standalone HTML**. This file can be downloaded and opened in the browser. When GitHub Pages is enabled by the repository owner, the deployment serves Neon Ledger City at the repository root and the existing Investigator under `/investigator`. GitHub Actions cannot enable Pages on behalf of an owner lacking repository administration permission.

## Architecture and provenance

The single-source module is generated by [scripts/generate_story_data.py](../scripts/generate_story_data.py). It reads the original report files and the exact experimental CSVs from:
- Temporal study: GitHub Actions run 45307007554
- Robustness study: GitHub Actions run 45308612475

The data generator refuses to build if required sources disappear or key expected counts change. If old experiment artifacts expire, the generated tracked data.ts can still be built and audited against its provenance.
