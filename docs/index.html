What this project can—and cannot—tell you

  • It helps rank transactions for human investigation using transaction attributes and graph context.
  • It cannot identify an arbitrary Bitcoin wallet owner or infer criminal guilt from a transaction ID.
  • Most Elliptic++ outcomes are unknown; unknown does not mean legitimate.
  • Graph features are calculated at the end of each time bucket; this is not instantaneous detection.
  • Earlier test periods informed later research decisions. Confirmed model reliability requires a genuinely new future dataset.
